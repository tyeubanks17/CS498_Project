# CS498_Project
Project for a study app to run on local machines

## Dependencies & Versions
**Python 3.13.9**

**Kivy 2.3.1**
Used for frontend
Install using `pip install "kivy[base]" kivy_examples`
N.B. Kivy is only supported up through Python 3.13
Demo at `.venv/share/kivy-examples/demo/showcase/main.py`
